# ✦ WanderLux — South India Travel Agency

> A modern, responsive Travel Agency Website built with **React.js** and **Bootstrap 5**, showcasing 12 curated tour packages across **Tamil Nadu** and **Kerala**.

🌐 **Live Demo:** [https://shri-2205.github.io/Frontend-Project/](https://shri-2205.github.io/Frontend-Project/)

## ✨ Features

- ✅ **Responsive Design** — Mobile, Tablet, Desktop
- ✅ **12 Tour Packages** — Tamil Nadu & Kerala
- ✅ **Category Filter** — Hill Stations, Beaches, Heritage, Wildlife
- ✅ **Package Detail Page** — Itinerary, Inclusions, Booking Form
- ✅ **Price Calculator** — Auto calculates total based on persons
- ✅ **Smooth Animations** — Hero zoom, card hover, button glow
- ✅ **React Router** — SPA Navigation (no page reload)
- ✅ **Booking Form** — Name, Email, Phone, Date, Persons
- ✅ **Contact Form** — With Google Maps embed
- ✅ **Team Section** — About page with team members

## 🛠️ Installation & Setup

```bash
# 1. Clone the repository
git clone https://github.com/shri-2205/Frontend-Project.git

# 2. Navigate to project folder
cd Frontend-Project

# 3. Install dependencies
npm install

# 4. Start development server
npm run dev
```

## 📦 Build for Production

```bash
npm run build
```

---

## 🌐 Deploy to GitHub Pages

```bash
npm run deploy
```
